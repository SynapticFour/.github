# Synaptic Four

Customer-sovereign infrastructure for genomics and clinical research. Stuttgart. Independent products, pin-based composition — not a bundle SKU.

**Start here:** [Related repositories](SUITE-OVERVIEW.md) · [Products](https://synapticfour.com/products)

These public repositories are maintained by the same organisation and are designed to work together. Each repository keeps its own version and license. For details on roles, maturity, and how the components relate to one another, see [SUITE-OVERVIEW](SUITE-OVERVIEW.md).
